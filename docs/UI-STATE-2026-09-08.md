## Settled design parameters (do not relitigate)

- **Wallet gate**: EVERYTHING above the game (letterbox stats line + frame bar) renders
  only for wallet-connected users. Gmail-only sessions see a blank top.
- **No boxes/chips** in the letterbox — plain text lines only; boxes made sub-pixel
  zoom drift visible.
- **Top letterbox**: `LIVE BURN FEED · TOTAL · TODAY · BURN TANK` — groups adjacent,
  one centered line at game width (`gameWidthStyle(z)` = `--game-display-w × z`,
  `liftStyle(z)` = `max(0, 58/z − 58)` clearance above the burn bar).
- **Frame bars**: scale with the game frame (plain CSS px, NO ZoomPanel).
- **Burn feedback**: top-bar counter slam + today chip ONLY. Overlays are retired;
  this supersedes any earlier "celebrations approved" decision.
- **Below the game**: world metrics bar only. Bottom letterbox stays deleted.
- Fonts: Orbitron + JetBrains Mono via `<link>` in index.html.

## Conventions proven this session

- Deploy = build → single commit → push → CF Pages (~5–25 min) → background
  watcher that greps the LIVE bundle for minification-proof markers
  (CSS rules / app-owned strings; vendor-shared strings verified by count
  delta, e.g. library "not connected" ×4 is not ours).
- Concurrent pushes from other sessions: `git fetch` → inspect incoming →
  rebase (never force-push).
- Never claim live without fresh bundle proof.
